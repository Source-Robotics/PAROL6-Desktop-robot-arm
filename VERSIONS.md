# PAROL6 versions

Which PAROL6 you have, and which files, firmware and manual go with it.

## Releases

| Release | Date | What it is | Firmware | Files |
|---|---|---|---|---|
| **V1.1** | 2026-11-04 | the files as of November 2026: revised building instructions, the small print bed parts, the pneumatic gripper holders, a reference image for every BOM part | 1, the same as V1 | [download](https://github.com/Source-Robotics/PAROL6-Desktop-robot-arm/releases/tag/V1.1) |
| V1 | 2025-03-08 | the first tagged release | 1 | [tag](https://github.com/Source-Robotics/PAROL6-Desktop-robot-arm/releases/tag/V1) |

## Which version do I have?

| | What differs | How to tell |
|---|---|---|
| Release V1 or V1.1 | the same mechanics and firmware; V1.1 adds the small print bed and gripper holder parts | either works with the current manual |
| Control board v2.0 or v1.2 | pluggable terminal blocks (v2.0) or spring contacts (v1.2); they work the same | look at the terminals |
